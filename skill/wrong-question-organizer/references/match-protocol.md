## 打分公式

```
score = 0.45 * numbers_overlap + 0.30 * formulas_jaccard + 0.20 * text_jaccard + 0.05 * visual
```

| 项 | 算法 | 说明 |
|---|---|---|
| `numbers_overlap` | 以较短集合为分母 `|A∩B| / min(|A|,|B|)` | 偏向召回：题干短、数值少时不会误判为 0 |
| `formulas_jaccard` | `|A∩B| / |A∪B|`，先去空格、小写 | 化学式/物理量几乎一一对应 |
| `text_jaccard` | 字符二元组集合的 Jaccard | 不依赖分词器，中文友好 |
| `visual` | `max(0, 1 - dhash距离/40)` | 只作 5% 的加分项 |

数值归一化：`6 V` / `6V` / `6.0V` → token `6v` 与数字主干 `6`；`109°28′` 保留度分符号。

## 为什么数值权重最高

模型读错"下列分子中键角最大的是"这句话的概率，远高于读错 `180°` 这种孤立数值；
而数值的区分力又极强——同一知识点的两道题，题面措辞可以八成相似，数值几乎不会撞。
把权重压在数值上，等于把匹配的可州性建立在模型最不容易出错的地方。

文本项只用来兜底（题面几乎无数字的纯概念题），并设为 20%：够区分，不够颠覆。

## 阈值与动作

```python
action = "auto"    if best >= 0.80
         "confirm" if best >= 0.45
         "reject"  otherwise
```

| 场景 | 典型分布 | 建议 |
|---|---|---|
| 同一教辅、题面完整 | 0.85–0.98 | 直接 auto |
| 数值识别漏了一两个 | 0.55–0.75 | confirm，把 top1 念给用户核对 |
| 图库里没有这道题 | < 0.35 | reject，转"存原照片 + 补库" |

**不要为了少问一句而调低 auto 阈值**。错题本的价值在于"复习时看到的就是当初那道题"，
一旦换题，这张卡片就永久失效，代价远大于多问一句。

## 视觉指纹怎么用

- `dhash` 由照片计算（`scripts/` 外的任意 dHash 实现，10×10、64 位或 100 位均可，需与索引同参）。
- 只在**照片干净**（无大面积手写遮挡、倾斜 < 3°）时提供；带手写时视觉项会被笔迹拉到 0，不必给。
- 视觉项还有一个更重要的用途：**入库去重**。两道题的 dhash 距离 ≤ 6 基本可以判定为同一题，避免同一题被记两次。

## 误匹配排查

按顺序看，别乱改权重：

1. `detail` 里哪一项是 0？——`numbers` 为 0 通常是模型把 `6 V` 读成了 `6V`（已归一，不会）或根本没读到数字。
2. top1 与 top2 的 `gap` 小（< 0.05）且都在 confirm 区 → 说明图库里存在近似题（同一题的变式），必须人工看。
3. 是否 `stem_text` 在 meta 里是空的？空的文本项会让 `text_jaccard` 恒为 0，总分上限被压到 0.75，
   导致本该 auto 的题掉进 confirm。
4. 全过程只看分数、不看"感觉"。匹配是算术，不是审美。
