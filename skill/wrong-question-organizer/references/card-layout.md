# PDF 版式规格（card-layout）

> 目标是"能打印、能裁剪、能贴本子、复习时看得清"。版式改动一律改 `assets/card_template.html`，不要改脚本。

## 纸张与边距

| 项 | 值 |
|---|---|
| 纸张 | A4 210×297mm |
| 页边距 | 上 8mm / 左右 10mm / 下 12mm |
| 每页题数 | 1–3 题（内容超出会自动降到 2 题） |
| 单题跨页 | **禁止**（`break-inside: avoid` + 自检） |
| 卡片间距 | 5mm |

## 卡片内部

```
┌───────────────────────────────────────────┐   ← 四角 5mm 裁切角标
│ [q_hx_0001] 化学键/键角  VSEPR  K01知识盲区    必修二 P88 │
├───────────────────────────────────────────┤
│  7. 下列分子中，键角最大的是                    │  ← 题面原图，宽度 170mm
│  A. H₂O   B. NH₃   C. CH₄   D. CO₂            │
├──────────────────────┬────────────────────┤
│ 我的错解 答案：C       │ 正确解 D            │
├──────────────────────┼────────────────────┤
│ 错在哪 把 CH₄ 的…     │ 复习节奏 11-16·11-17…│
└───────────────────────────────────────────┘
│ 第 1 题 · 图库命中 0.950                     │
```

| 元素 | 规格 |
|---|---|
| 题号 | 9.5pt 粗体，方括号包裹，全局唯一 |
| 知识点标签 | 8pt，0.5pt 边框，圆角 1mm |
| 错因标签 | 8pt，红色 `#c0392b` 边框 |
| 题面图 | `max-width:100%`，实际宽度 ≈170mm，正文 ≥9pt 字号 |
| 四宫格 | 8.6pt，1.5 倍行高，细线 0.5pt `#ccc` |
| 我的错解 | 红 `#c0392b` |
| 正确解 | 绿 `#1e6b3a` |
| 复习节奏 | 1/2/4/7/15/30 天后日期，`MM-DD` |

## 打印友好

- 纯白底，**不用深色块**（省墨、复印不糊）。
- 不用背景色块区分模块，用细线——复印机会把浅灰块压成脏灰。
- 裁切角标放在卡片四角而非页面四角：目的是裁下单题贴本子，不是切整页。
- 页脚只有"第 N 题 · 图库命中 x.xxx"，不印生成时间，避免过期信息进入纸质档案。

## 常见改动

| 想改 | 改哪里 |
|---|---|
| 每页题数 | `card_template.html` 的 `.card` 外边距 + 题面图最大宽度 |
| 加"解题关键步骤"一格 | `.grid` 从 `1fr 1fr` 改两行三列，或在 `.cell` 里加一段 |
| 不要"我的错解" | 删掉对应 `.cell`，同时把 `.grid` 改成单列 |
| 分学科分册 | `render_pdf.py --split-by subject`，每册加封面目录页 |
| 改成 A3 两页合一 | `@page { size: A3 }`，其余不动 |

## 自检项（`--verify`）

1. 单题跨页 = 0：抽 PDF 每页文字位置，检查同一 `id` 是否跨页出现两次。
2. 重复题号 = 0。
3. 空题面 = 0（`img_data_url` 为空的卡片直接判失败）。
4. 词表外知识点 = 0。
